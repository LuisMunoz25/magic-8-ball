# 🎱 Magic 8-Ball (Python)

A simple Python program that simulates a **Magic 8-Ball**, providing random answers to yes-or-no questions.

This project was created as a learning exercise while studying Python on Codecademy.

---

## 🚀 How It Works

- The program generates a random number between **1 and 9**
- Each number corresponds to a predefined Magic 8-Ball response
- The program prints the user's question and a randomly selected answer

---

## 🛠 Technologies Used

- Python 3
- `random` module

---
